# zerho Reproducible Benchmarks

Every performance number published for **zerho** is measured with the built-in `zerho bench` harness on a real compiled `--release` binary — never synthetic micro-loops. Any developer can reproduce and verify these measurements locally in under 30 seconds.

## 1. Reference Hardware & Environment

| Property | Value |
| :--- | :--- |
| **zerho version** | `0.7.0` (`--release`, single native binary: **16.60 MB** / `17,404,416` bytes) |
| **Rust compiler** | `rustc 1.96.1 (31fca3adb 2026-06-26)` |
| **CPU** | `AMD64 Family 25 Model 80` (AMD Zen 3, **16 logical threads**) |
| **Operating System** | `Windows 11 x86_64` (`Microsoft Windows NT 10.0.26300.0`) |
| **Pipeline flags** | `scope_hoisting = true`, `minify = true` (`oxc_minifier` + mangler), `brotli = true` (`.br`), `security.sri = true` (SHA-384), `security.csp = true`, `security.secret_scan = true` |
| **Raw JSON snapshot** | [`benchmarks/results.json`](./results.json) |

## 4. Reproduce & Verify Yourself

```bash
# 1. Build the optimized native binary
cargo build --release -p zerho-cli

# 2. Run on real workspace examples
./target/release/zerho bench --config examples/basic-ts/zerho.toml --iterations 20
./target/release/zerho bench --config examples/react-tsx/zerho.toml --iterations 20

# 3. Stress-test a deterministic 500-module TypeScript graph (or 1000!)
./target/release/zerho bench --synthetic 500 --iterations 5

# 4. Export machine-readable JSON with your own CPU/OS metadata
./target/release/zerho bench --synthetic 500 --iterations 5 --json
```

> On Windows PowerShell, replace `./target/release/zerho` with `.\target\release\zerho.exe`.
